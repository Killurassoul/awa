# Awa ❤️ — une petite surprise

Une expérience web personnelle et responsive créée pour Awa, avec une direction artistique éditoriale, des chapitres animés et des interactions entièrement côté client.

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

Le projet est compatible avec un déploiement Vercel standard. L’ambiance optionnelle utilise une courte génération sonore Web Audio locale : aucun fichier audio ou service externe n’est requis.
